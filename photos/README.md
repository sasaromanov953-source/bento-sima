# Фото для сайта

Положите сюда файлы с этими именами, и они сами встанут на сайт вместо иллюстраций:

| Файл | Где на сайте |
|---|---|
| `hero.jpg` | Заставка: розовый бенто «Добро пожаловать домой» в коробке |
| `work-mame-flowers.jpg` | Примеры работ: белый бенто «Маме» с цветами |
| `work-desserts.jpg` | Примеры работ: набор из 4 десертов «Маме» |

Остальные плитки «Примеров работ» пока нарисованы. Чтобы поставить фото,
добавьте элементу с `data-cake` в `index.html` атрибут `data-photo="photos/имя.jpg"`.
